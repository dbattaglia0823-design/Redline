Unmodified font binaries obtained from the installed Poppler runtime distribution.
Embedded copyright records were inspected before bundling. The accompanying
upstream license texts were retrieved from google/fonts/ufl/ubuntu/UFL.txt and
adobe-fonts/source-code-pro/LICENSE.md. Both families permit embedding in this game.
No Windows system font files are redistributed.

`AutomotiveUI` defines role sizes, weights, colors and the shared native Theme.
The legacy drawing adapter and `glass_theme.tres` use the same bundled families,
so menus awaiting structural migration remain consistent across platforms.
