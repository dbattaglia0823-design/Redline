# Unified upgrades UI

There is now one upgrade overview with all fifteen categories. Each item opens the same secondary window, with only its relevant stage, component, gearbox and customization sections. The car-hotspot workshop and global basic/advanced navigation have been removed from the visible flow.

Close or Escape returns to the overview and retains the selected category. The underlying menu cannot be clicked through. Dyno returns to the same item window; vehicle testing is a separate utility on the overview. Category-specific presets change only the relevant settings. Transmission previews emphasize shift duration and torque capacity, rather than unchanged engine horsepower.

The existing purchase, ownership, compatibility, save and simulation systems are reused. No vehicle physics, upgrade ownership or progression has been replaced. Tests traverse all fifteen windows, verify scoped components and blocked background controls, and retain purchase, transmission, tuning, keyboard/mouse/multitouch, dyno and race-flow checks. The full regression suite passed. Screenshots of stage, component and customization windows were inspected.

Layout remains on the existing scalable landscape canvas; physical-phone ergonomics remain unverified. The previously documented intermittent Windows shutdown issue remains a monitoring item.
